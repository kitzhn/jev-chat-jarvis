# 联系人画像与关系模型

此功能仅保存用户主动维护的联系人资料，不包含任何预置个人数据，也不会从聊天内容自动推断好感度或对方真实心理。

## 数据结构

每个联系人可维护：

- 名字与跨 App 别名
- 关系类型
- 当前关系阶段
- 好感度（0–100）
- 信任度（0–100）
- 亲密度（0–100）
- 画像标签
- 性格 / 长期特征
- 沟通偏好
- 边界 / 忌讳
- 备注
- 原有本地聊天历史

所有数据仍保存在 App 私有目录的 `filesDir/kb/contacts.json` 和 `filesDir/kb/logs/` 中。

## 好感度量级

| 分数 | 阶段 |
| --- | --- |
| 0–19 | 冷淡 |
| 20–39 | 疏远 |
| 40–59 | 普通 |
| 60–79 | 亲近 |
| 80–94 | 信赖 |
| 95–100 | 特别亲密 |

默认值为 50。联系人列表提供 ±5 快捷调整，也可以进入联系人画像直接填写 0–100 的数值。

## AI 上下文

当聊天标题命中联系人时，关系模型会作为背景信息提供给判断 / 回复流程，包括关系类型、关系阶段、三项分数和画像字段。

上下文会明确标记这些资料是“用户手动维护的关系模型”，不能当作对方真实心理或客观事实。

## 兼容性

旧版本 `contacts.json` 没有新字段时：

- 好感度默认 50
- 信任度默认 50
- 亲密度默认 50
- 其它新增字段默认为空

因此无需单独的数据迁移步骤。
